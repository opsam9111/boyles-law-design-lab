# Boyle's Law Design Lab

**One Lesson Through Three Frameworks** is a standalone, accessible Cool Resource created for AIL 601. It applies TPACK, SAMR, and Universal Design for Learning (UDL) to a realistic face-to-face middle-school science lesson on Boyle's law.

## What the resource includes

- An interactive pressure–volume model
- Optional spoken description and pausable particle motion
- A captioned, optionally narrated Boyle's law micro-lesson
- English, Spanish, French, and Yoruba core-prompt options
- Larger-text and high-contrast display controls
- Written, visual, and local audio-recording response choices
- A realistic middle-school instructional scenario
- Applied explanations of TPACK, SAMR, and UDL
- A same-scenario framework comparison matrix
- A three-question framework decision challenge
- An accessible five-phase lesson blueprint
- A scored sample student explanation showing equivalent evidence across written, visual, and audio responses
- APA-style in-text citations and references
- An accessibility statement and transparent design limitation

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository named `boyles-law-design-lab`.
2. Upload the contents of this folder. `index.html` must remain at the repository's top level.
3. Open the repository's **Settings**.
4. Select **Pages** from the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then select **Save**.
7. Wait a few minutes and refresh the Pages settings. The site should appear at:
   `https://YOUR-USERNAME.github.io/boyles-law-design-lab/`

## Local preview

The resource is build-free. Open `index.html` directly in a current browser, or serve the folder through any local static server.

## Accessibility notes

The site includes semantic HTML, keyboard-operable controls, visible focus indicators, adjustable text size, a high-contrast mode, responsive layouts, an ARIA live description of changing simulation values, reduced-motion support, optional browser speech synthesis, visible captions, a transcript, and multiple response formats. The core relationship is communicated through movement, numerical values, text, audio, and a formula.

The language selector changes the complete learner-facing page—including navigation, instructions, simulation descriptions, framework explanations, feedback, captions, and speech-synthesis language—between English, Spanish, French, and Yoruba. Framework acronyms, equations, author names, and URLs remain unchanged for accuracy. Translation requires an internet connection, translations should be reviewed by fluent speakers before formal classroom adoption, and spoken output depends on the voices available in the learner's browser.

The optional external PhET simulation should be tested with the assistive technologies used by the intended learners. The lesson retains tactile, verbal, numerical, and printed alternatives.
